First working Flutter preview of Koshur Noor: offline prayer times, Kashmir-first locations, a next-prayer countdown, monthly timetable, fixed Qibla bearing guide, twelve Arabic duas with Kashmiri meaning drafts, favourites, prayer log, tasbih, night palette and bundled Nastaliq.

Download **Koshur-Noor-Android-arm64.apk** for a modern 64-bit ARM Android phone (Android 7.0+). This preview uses a development signing key; it is for testing and sideloading, not Play Store publication. Android may ask you to allow installation from the browser used to download the APK.

Kashmiri meanings are explicitly draft translations awaiting review. Confirm calculated prayer times with your mosque. Qibla is a true-north bearing guide, not a live compass. No background alarms or audio playback are included in this version.

Validation: ten Flutter tests passed; analyzer clean; web production build and mobile browser checks passed; APK build and signature verification passed. No physical Android device installation test was available. The APK requests no internet or location permission.

Source is in apps/koshur_noor on main and in the attached Flutter source ZIP. Preserve your own signing key for later production releases.
