# Kashmiri training review queue

The training-memory builder accepts only attributed, explicitly paired Kashmiri–English examples. The following sources remain outside training memory until transcription or alignment is reviewed:

- JKBOSE Class I (2024): 80 OCR pages; character and spacing substitutions remain.
- Grierson dictionary scan (1932): 1,290 OCR pages; historical romanization and scan OCR require alignment with modern Perso-Arabic forms.
- *Kaishrik Grammer*: 252 pages; the confidence audit accepted no usable prose lines.
- Other monolingual corpora: useful for fluency analysis, but not English–Kashmiri translation pairs.

Promote an item only after recording the Kashmiri text, English translation, transliteration, grammatical metadata, source page, reviewer note and review status.
