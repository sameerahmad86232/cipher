ABOUT THE PROJECT

A practical home for
Kashmiri words.

Koshur Lughat is a searchable Kashmiri–English dictionary and an experimental two-way sentence translator built around the Perso-Arabic script.

What’s included

More than 18,000 searchable records, separately indexed spelling alternatives, romanized Kashmiri, English meanings, grammatical categories and usage examples.

Still improving

The sentence translator currently uses lexical phrase matching. A reviewed parallel corpus and neural model backend are needed for fluent grammar and idioms.
