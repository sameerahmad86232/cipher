ABOUT THE PROJECT

A practical home for
Kashmiri words.

Koshur Lughat is a searchable Kashmiri–English dictionary and a browser-based neural sentence translator for the Perso-Arabic script.

More than a word list

Multiple meanings are grouped by headword. Sourced entries include sense context, transliteration, IPA, examples, inflected forms and related vocabulary where supplied. A separate historical romanized collection preserves 20,643 older entries without presenting them as modern spellings. The complete Koul book OCR is searchable by page and clearly labeled machine output. Form counts are separate from definition counts.

Real models, honest limits

IndicTrans2 200M models and optional desktop 1B models translate sentences with three-beam decoding. Translation is automatic, not native-speaker reviewed. Kashmiri needs much more evaluation; this site does not claim world-leading accuracy.

Sources & reuse

We import explicitly identified Kashmiri definitions and translation-table pairs, not guessed meanings from monolingual or audio corpora. Gated datasets need their owners’ access approval. Original vocabulary has unresolved licensing; Wiktionary adaptations are CC BY-SA 4.0, and Kaeshir Dictionary data is MIT licensed. Read the source and model documentation and Kaeshir license before redistribution.

Reference book

We check existing entries against Koul, Raina and Bhat’s Kashmiri–English Dictionary for Second Language Learners (2000). The project owner reports rights-holder approval for public reuse. We add manually checked entries and page-linked references; the scan’s machine OCR is too unreliable for an unreviewed bulk import.

Privacy & storage

Sentences are processed locally in a web worker. Downloading models contacts Hugging Face and the pinned runtime CDN. Recent searches and model cache stay in this browser and can be cleared.
