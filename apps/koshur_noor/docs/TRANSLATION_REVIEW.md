# Translation review handoff

Edit `assets/data/duas.json` using stable IDs. Preserve Arabic and source reference independently of Kashmiri edits. Add an explicit reviewer/date before changing `reviewStatus` from `draft-awaiting-owner-review` to `owner-reviewed`. Do not treat generated drafts as owner-approved training data.

Meaning guides from the conversation: use the owner's preferred native vocabulary and Nastaliq, distinguish person and number in verbs, avoid Urdu substitutions when a natural Kashmiri construction is known, use پوٗز for truth, نِکاح for marriage, وَتہِ for path and the corrected honorific forms in context. These preferences require contextual application, not blind replacement.

Current content: 11 Quran supplications/excerpts and one hadith supplication, with exact references shown in-app. The correction template includes ID, source and current wording for traceable feedback. Settings can copy all meaning records as JSON.
